# FAQ and fit-guide previews

Captured from the production frontend with fixture public API responses. The questions, answers, fit-guide text, example.edu links, and phone number are preview data rather than final Peer2Peer content. No anonymity or safety draft answers were published.

- [Mobile, 375px](faq-375.png): stacked guide lists and an expanded FAQ answer.
- [Desktop, 1280px](faq-1280.png): guide lists side by side, followed by category groups.
- [No published FAQs, 375px](faq-empty-375.png): the guide remains and the FAQ groups are hidden.

Browser checks covered category and question order, Enter/Space toggling, arrow-key navigation, Markdown answers, website and telephone resource links, controls at least 44px tall, and no horizontal overflow. Screenshots finish CSS animations before capture; expanded answers were measured to ensure their text is not clipped. Each fresh preview server used the same production build with populated or empty FAQ responses.
